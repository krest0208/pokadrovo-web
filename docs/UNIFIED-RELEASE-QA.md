# Проверка единой поставки — 18 октября 2026

Поставляется существующий проект с гостевым режимом и настоящим Node.js/SQLite-сервером. Домен, DNS, TLS, Sites и REG.RU не изменялись.

## Выполнено

- TypeScript: без ошибок; Vite production build собран.
- 57 серверных тестов: прежний режим аккаунтов, изоляция проектов, владелец, CSRF, cookie, OAuth-контракт, шифрование API-ключа, новый гостевой режим.
- 5 тестов отдельного запуска: готовая сборка без npm, создание владельца без стандартного пароля, сохранность базы/ключа, перезапуск режима аккаунтов, гостевые страницы и сохранение API-настроек после перезапуска.
- 5 тестов встроенной сборки/хранения: формат фрагмента, изоляция предпросмотра, недоступное хранилище, некорректные локальные данные и отдельное гостевое пространство основной версии без отправки документов серверу.
- DOM-эмуляция настоящего `Studio`: главная без приглашений к регистрации → пустой монтажёр → библиотека гостя → повторное открытие проекта. Единственный сетевой запрос в этом сценарии — получение режима/сеанса. Ошибок выполнения не получено.
- YAML доменной конфигурации разбирается; приложение не имеет опубликованного порта; HTTPS включается отдельным профилем `publish`; приватный том отделён от образа.
- Архив собирается по разрешённым каталогам. Скрытые приватные папки, node_modules, .git, реальные .env, базы и ключи не включаются. Итоговый состав и хеши перечислены в RELEASE-MANIFEST.json.

## Не проверялось в этой поставке

Настоящий браузер с воспроизведением/экспортом медиа, длинный видеопроект, Docker Engine, реальный VPS, выпуск TLS-сертификата, внешний OAuth и вызов нейросети. Тесты DOM не подтверждают качество отрисовки canvas, звук или кодирование видео.

## Что изменилось в поведении

По умолчанию регистрация и пользовательский вход выключены на сервере. Гость может открыть `/studio` и `/projects`; серверные документы, настройки и ключи по-прежнему закрыты. Существующие учётные записи не удаляются, прежний режим можно включить через `POKADROVO_ACCOUNTS_ENABLED=1`.

Админка находится по `/krest0208!!!`; публичных ссылок на неё нет. Раздел «Подключение нейросети» сохраняет зашифрованный ключ с подтверждением владельца. Статус `connected: false` остаётся правдивым: обработчик запросов к модели ещё не создан.
