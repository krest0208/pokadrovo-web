# Owner admin 0.7 — проверено и не проверено

## Реальная серверная проверка

25 тестовых сценариев Node.js `node:test` выполнены с настоящими HTTP-запросами к серверу, изолированными SQLite-базами и случайными тестовыми паролями. Это не тестовые пароли приложения: production-владелец создаётся пользователем через CLI.

Проверены scrypt, отсутствие публичного setup, единственный владелец, закрытие приватных API для гостя и поддельной сессии, универсальная ошибка логина, HttpOnly/SameSite, CSRF/Origin/Host, отзыв старой сессии новым входом, logout, 30-минутный idle, абсолютные 12 часов, лимит попыток, HTTPS-cookie, закрытие приватных файлов, AES-GCM-хранение и отсутствие чтения ключа, запрет произвольных URL провайдера, смена пароля, TOTP с защитой от повторного кода, согласие/подпись события, дедупликация, фактическая агрегация, хеширование идентификаторов, DNT/GPC, удаление событий при отказе, отключение аналитики, лимит тела запроса, fail-closed при потере master.key.

## Интерфейс

28 изолированных проверок Chromium прошли на HTML/CSS/JS панели с явной тестовой заглушкой API. Проверены экран входа, переключение разделов, очистка полей пароля/ключа, фильтр 7/30 дней, таблица, график пустого состояния, статусы API, журнал, logout и отсутствие горизонтального переполнения на 320–1920 px.

На снимках показано пустое тестовое состояние (нули), не текущие показатели сайта пользователя. Заглушка существует только в локальном тестовом скрипте, **не включена в приложение**.

Полный браузерный сетевой сценарий заблокирован политикой браузера среды (`ERR_BLOCKED_BY_ADMINISTRATOR` для localhost). Ограничение не обходилось. Поэтому изолированные UI-проверки не выдаются за end-to-end тест браузера с реальным сервером. HTTP API отдельно проверены Node.js.

Новый analytics.ts отдельно прошёл строгую проверку TypeScript. Полная production-сборка выполняется штатным GitHub Actions после коммита; её статус указывается отдельно в результате работы. Команда сборки сначала выполняет `npm run test:admin`, затем TypeScript и Vite. Настройка CI не включает публикацию на хостинг.

## Не проверено

Настоящий домен/TLS/reverse proxy, длительная нагрузка, установка владельца на компьютере пользователя, реальные сторонние ключи, вызовы модели, SMS/почта, пользовательская регистрация, платежи и сторонняя аналитика не запускались. Новый backend не включён в одиночный HTML: такой файл не может обеспечить серверную авторизацию.

Проектная модель, рендеринг, таймлайн, AI-planner и Android не переписаны. В существующие saveProject/download добавлены только безопасно изолированные события статистики, которые не блокируют сохранение/скачивание при ошибке.
