# Главная: анимации при прокрутке и обновление логотипа

Изменения от 17 октября 2026 года. Работа только в веб-репозитории, без публикации на хостинге.

## Поведение

- IntersectionObserver наблюдает 10 независимых зон: заголовок, коллаж, бриф, описание процесса, режиссёрский лист, видение продукта, план развития, проекты, вопросы, подвал.
- Входные анимации запускаются, когда видно не менее 12% блока. Они проигрываются один раз; непрерывное приближение фотографий продолжается, пока блок виден. За границей экрана выполнение приостанавливается и возобновляется при возвращении.
- Загруженное пользователем видео воспроизводится без звука, с playsInline и loop, только в видимом блоке. Если браузер блокирует автовоспроизведение, ручной просмотр остаётся доступен.
- При открытии просмотра кадра, отключении движения и системном prefers-reduced-motion анимации отменяются, а видео останавливаются. Смена настройки ОС учитывается без перезагрузки. В скрытой вкладке анимации приостановлены.
- Контент не скрывается до прокрутки. При отсутствии IntersectionObserver остаётся читаемая статичная страница.
- При удалении компонента освобождаются observer, слушатели событий и анимации.

## Интерфейс

Удалена верхняя линейка из JSX. Исправлена минимальная ширина сетки в блоке процесса, перенесены подписи на фото так, чтобы их не перекрывал портрет, ограничены размеры текстовых колонок. Кнопка «В монтажную» стала основной синей кнопкой в шапке; используется существующий onContinue.

Новый знак: синий квадрат со скруглениями, две белые угловые скобки кадра и треугольник воспроизведения. Один компонент BrandMark для всех экранов и одинаковые SVG в public. Без прежних мелких прорезей.

## Проверки

54 из 54 проверок прошли в Chromium на автономном HTML-предпросмотре. Проверены запуск, пауза за экраном и возобновление; движение фотографий; muted-видео; глобальное отключение и настройка ОС; диалог, вложения, бриф, CTA, тёмная тема и очистка после unmount. Заголовки, основной текст, шапка, форма и элементы управления проверены на 17 ширинах: 320, 360, 375, 414, 640, 650, 651, 768, 950, 1024, 1100, 1101, 1190, 1280, 1366, 1440, 1920 px. Горизонтального переполнения этих элементов не обнаружено.

Ограничение проверки: автономный preview использует прежнюю React 16-оболочку; компиляция основного React 19-проекта проверяется отдельно штатным GitHub Actions. Это не полная повторная проверка экспорта/редактора. Safari, Firefox и реальные мобильные устройства в этом прогоне не проверялись.

Монтажный движок, Studio.tsx, зависимости, workflow и Android-проект не изменены. ИИ-обработка не подключалась.
