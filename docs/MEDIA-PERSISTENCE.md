# Сохранение и повторное открытие исходников

Исходники хранятся в IndexedDB того же браузера, отдельно для каждого аккаунта. Настройки монтажа сохраняются локально сразу после изменения; отправка метаданных на сервер объединяет быстрые последовательные правки. При выходе из редактора отложенное сохранение завершается в прежнем аккаунте и не переносится в другой.

Исправлено восстановление объектов File: их поле name доступно только для чтения. Название клипа передаётся в инспектор отдельно, исходный File не изменяется. Каждый исходник восстанавливается независимо; отсутствующий или повреждённый файл не прерывает загрузку остальных и не удаляет клипы из проекта.

Пачка импорта сохраняет Blob/File и метаданные каждого завершённого клипа сразу. Выход во время импорта больше не отменяет сохранение предыдущих завершённых файлов. Незавершённый файл может потребовать повторного добавления.

Файлы не загружаются на сервер вместе с метаданными проекта. На другом устройстве, в другом браузере или после очистки данных сайта их необходимо выбрать заново. Изменение кода не восстанавливает уже удалённые данные браузера; сохранённые ранее File восстанавливаются без повторного импорта. JSON содержит монтаж, без байтов исходников.

Проверки: `node --test server/tests/media-persistence.test.mjs`. Они воспроизводят File с полем name только для чтения, повторное открытие после пересоздания приложения, пропавший первый файл, отмену восстановления, разделение аккаунтов, выход во время пачки импорта и сохранение правки перед навигацией. Модель IndexedDB в проверке сохраняет свойство name только для чтения; декодирование мультимедиа не является предметом этих проверок.
