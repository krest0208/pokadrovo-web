# Пробный анализ видео и звука

Реализован серверный адаптер Qwen Omni и его связь с редактором. Реальный доступ к модели
проверяется только запросом с вашим ключом. В репозитории нет API-ключа; отсутствие ключа
не подменяется демонстрационным ответом. Результаты автоматических тестов используют
подставной HTTP-провайдер, а не платную модель.

Схема двух независимых провайдеров, бесплатной пробы и будущего тарифа:
[AI-ACCESS-AND-YANDEX.md](AI-ACCESS-AND-YANDEX.md). Яндекс настраивается отдельно
и пока получает только задание/структуру проекта, без исходных медиа.

## Включение владельцем

1. Войти в уже созданный аккаунт владельца, открыть его админ-панель → «Подключение нейросети».
   Если аккаунт владельца ещё не создан, сначала завершить его отдельную настройку:
   [ADMIN-ACCOUNT.md](ADMIN-ACCOUNT.md). Обновление сайта не создаёт и не меняет пароль.
2. Создать ключ в собственном Alibaba Cloud Model Studio с доступом к `qwen3.8-omni-flash`.
   Проверить возможность использования и оплаты сервиса для своего аккаунта и страны.
3. Выбрать Qwen Omni и модель `qwen3.8-omni-flash`. Вставить Base URL Chat Completions рабочего
   пространства и ключ из одного региона. Пример структуры адреса:
   `https://WORKSPACE.ap-southeast-1.maas.aliyuncs.com/compatible-mode/v1`.
   Для старых рабочих пространств также допускаются документированные домены DashScope.
4. Включить Qwen для теста администратора, подтвердить текущим паролем и сохранить.
   Для бесплатной пользовательской пробы отдельно включить её переключатель.
   Сохранение не делает платного запроса. Статус «Готова к пробе» не означает проверенный ключ.
5. В редакторе включить режим Reels (9:16), подготовить проект до 60 секунд и импортировать
   короткий исходник MP4 со звуком. После первого пользовательского анализа также доступен WAV PCM.
   Открыть панель ИИ, написать задачу, выбрать файл и подтвердить его передачу в Qwen.
   Нажать «Разобрать файл и предложить монтаж».
6. Проверить описание, речь, звуковые события и таймкоды. Они относятся к исходному файлу.
   Предложенный план дополнительно проверяется и симулируется редактором. Применение —
   отдельной кнопкой, отмена — одним действием. Пустой план допустим: правка ради результата
   не создаётся. Если модель ошиблась в операции, весь план отклоняется.

Ключ вводится только в защищённой панели сайта, не в чате, GitHub или параметрах браузера.
После сохранения сервер не возвращает ключ в интерфейс.

## Границы первого теста

- Один целый исходник до 60 секунд и 12 MiB, MP4 или WAV PCM. Контейнер и длительность
  проверяются сервером до вызова модели. Обрезка клипа на таймлайне не уменьшает исходник.
- Обычная кнопка ИИ отправляет только текст, структуру проекта и последний анализ этого
  файла в текущем сеансе редактора. Для файла нужна отдельная кнопка и согласие.
- Гости не могут запускать модель. Бесплатная проба для зарегистрированных аккаунтов
  открывается отдельным переключателем: один проект, три запроса, семь дней с первого запуска.
  Ошибка провайдера возвращает попытку в пробу; суточный предел API остаётся потраченным.
  Владелец тестирует без пользовательского лимита, но в пределах общего расхода API.
- До 12 попыток в сутки на сайт, обновление лимита в 03:00 по Москве (00:00 UTC).
  Считаются и ошибки после запуска запроса: провайдер мог успеть обработать материал.
- Один запрос одновременно, максимум 4096 выходных токенов и 90 секунд ожидания провайдера.
  Автоматических повторов нет. Повтор того же requestId отклоняется.
- При отмене прерывается HTTP-вызов; это не обещание отмены обработки или списания у провайдера.
- Видео со встроенным звуком отправляется как `video_url` с Base64-данными; WAV — как
  `input_audio`. На диск сервера Покадрово файлы не записываются. В журнале остаются только
  время, статус, модель, аккаунт, режим, тип доступа, длительность и реально возвращённые счётчики токенов.
  Хранение запросов у провайдера определяется его условиями и настройками аккаунта.
- Анализ в редакторе хранится в оперативной памяти, не переносится между устройствами
  и не заменяет постоянную память по всему длинному проекту.
- Ошибки провайдера не раскрывают его ответ, ключ или отправленное содержимое.
  Адреса назначения ограничены API Alibaba Cloud, внешние URL медиа не принимаются.

Пока не реализованы: разбор исходников на десятки минут, полноценная история диалога,
шумоподавление/разделение дорожек, внешние библиотеки лицензированной музыки и звуков,
автоматическая загрузка найденных записей и серверный экспорт. Модель не получает
инструмента веб-поиска и не может скачивать файлы или выполнять команды.

## Проверка качества на реальном материале

Первый ролик: 15–60 секунд с понятной речью, действием в кадре и заметным фоновым звуком.
Сверить события и таймкоды с исходником, проверить, не выдумана ли речь, просмотреть каждую
предложенную правку, затем сохранить фактические токены из результата/админки. Стоимость
полного монтажа не выводится из текстового тарифа: её нужно измерять на выбранной модели.

## API и документация

- `GET /api/ai/status`: доступность для текущего пользователя, ограничения, без ключа.
- `POST /api/ai/edit-plan`: сессия, same-origin, CSRF, проверка аккаунта и его пробы; явное согласие на media.
- `GET /api/admin/ai/usage`: последние 20 запросов, только владелец.
- `PUT /api/admin/settings`: прежние настройки + `endpoint`, `aiEnabled`, `trialEnabled`; с повторным паролем.

Официальные источники, проверенные 19.10.2026:

- https://www.alibabacloud.com/help/en/model-studio/qwen-omni
- https://www.alibabacloud.com/help/en/model-studio/qwen3-8-omni-flash

API принимает MP4 со встроенным аудио и локальные Base64-данные. JSON Mode проверяет
синтаксис, поэтому схема, таймкоды и монтажные операции проверяются отдельно нашим кодом.
