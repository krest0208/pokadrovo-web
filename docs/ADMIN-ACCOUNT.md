# Отдельный аккаунт администратора

Обычная регистрация по почте создаёт только роль `user`. Единственная учётная запись владельца находится отдельно в таблице `owner`; публичной регистрации администратора и назначения роли через запрос нет.

На pokadrovo.ru администратор использует обычную кнопку «Войти»: вводит свой отдельный логин и пароль, при включённой двухфакторной защите — также код из приложения. Только подтверждённый сервером сеанс владельца получает `role: owner` и адрес панели. Кнопка «Админ-панель» доступна в меню главной страницы, профиле и редакторе. Обычные пользователи и гости её не видят; обращения к API панели отклоняются независимо от интерфейса.

## Первое создание на существующем VPS

В серверном терминале выполнить вручную:

```sh
runuser -u pokadrovo -- env POKADROVO_DATA_DIR=/var/lib/pokadrovo node /opt/pokadrovo/app/server/setup.mjs --generate
```

Команда сама создаёт случайный логин `pkadmin-…` и случайный пароль из 43 символов, показывает их только в интерактивном терминале и сохраняет лишь хеш пароля в приватной базе. Сохранить данные в менеджере паролей. После входа их можно изменить в разделе «Защита доступа» админ-панели.

Команда отказывается работать при перенаправлении вывода и **никогда не заменяет существующего владельца**. Повторный запуск безопасно завершается ошибкой. Не использовать `--reset` для обычного обновления: он предназначен для отдельного восстановления доступа и сбрасывает двухфакторную защиту.

Обновление кода не создаёт аккаунты и не меняет существующие пароли, TOTP, пользователей или проекты. Прямой вход `/krest0208!!!` сохранён. Срок действия прав администратора прежний: 30 минут бездействия, максимум 12 часов; новый вход завершает старый сеанс. Выход удаляет сеанс на сервере.
