# Предпросмотр в чате без регистрации

По просьбе владельца от 18 октября 2026 размещение на REG.RU приостановлено. Для просмотра в чате добавлена отдельная автономная сборка. Она использует существующие AiHome, HomeFormats, медиадвижок, монтажёр, инструменты и оформление административной панели. Нового сайта вместо существующего нет.

Верхние кнопки: «Сайт», «Монтажёр», «Проекты», «Админ-панель». В этой сборке нет регистрации, входа или запросов к API аккаунтов. Сайт сразу открывает монтажёр, импорт файлов, таймлайн, текст, музыку, скорость, звук, трансформации и исходный диалог экспорта. Возможности видеоэкспорта зависят от браузера и разрешений встроенного окна; ИИ остаётся неподключённым.

Проекты и локальные события имеют отдельное пространство `pokadrovo.chat-preview.v1`; медиа — отдельную IndexedDB. Приватные серверные базы, аккаунты и ключи не читаются. При запрете хранилищ встроенным окном используется память на время его жизни. Доступен экспорт параметров проектов в JSON; исходные медиа следует хранить отдельно.

Панель показывает реальные события и проекты только этого предпросмотра. Здесь можно открыть проект, посмотреть форматы, журнал локальных действий и сохранить название будущего ИИ-провайдера/модели. Отдельный пункт «Подключение нейросети» открывает форму выбора провайдера, модели и видимое отключённое поле API-ключа. В хранилище записываются только provider и model; реальные ключи не принимаются. Статус всегда сообщает, что нейросеть ещё не подключена. OAuth и настройки серверной защиты в предпросмотре отсутствуют. В рабочем Node.js-сервере проверки владельца и закрытые API сохранены, а тот же раздел позволяет сохранить зашифрованный API-ключ с подтверждением пароля владельца. Серверный обработчик вызовов нейросети пока не реализован.

Сборка: `npm run preview:chat` или `node tools/build-chat-preview.mjs /absolute/path/preview.html`. Получается один автономный HTML-фрагмент для встроенного окна; сервер и внешние загрузки не нужны. Исходные шрифты и изображения включены внутрь. Обычная команда `npm run build` по-прежнему собирает серверную версию.

Чтобы сразу открыть раздел подключения: `node tools/build-chat-preview.mjs /absolute/path/pokadrovo-ai-preview.html --ai-settings`. Остальные разделы сайта и монтажёра доступны через верхнее меню.

Проверки: TypeScript, `node --test tests/chat-preview*.test.mjs`, проверка отсутствия сетевых API и аккаунтных модулей в автономном bundle. Сборка извлекает только содержимое body административного шаблона, удаляет серверные скрипты и не включает head, внешние стили или теги документа. Строка React с инертным script-элементом экранируется для обработчика встроенных фрагментов. Регрессионный тест проверяет именно итоговую сборку по правилам валидатора визуализаций.

При исправлении ошибки запуска отдельно проверены в DOM-эмуляции: открытие раздела ИИ, сохранение и повторное открытие настроек, все пункты административного меню и переход на главную. Проверки выполнены с доступным хранилищем и с отказом доступа как в изолированном окне. Это не проверка визуального отображения в настоящем браузере; экспорт видео в окне чата не проверялся.
