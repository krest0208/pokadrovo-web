Не подключён

Не передавайте пароли соцсетей

Пользователь вводит пароль только на странице Google, Facebook или Instagram. Здесь сохраняются ключи приложения, не пароли посетителей.

Создайте OAuth-приложение, добавьте Redirect URI и разрешённый домен. Для Meta используйте HTTPS. Для входа посторонних пользователей могут потребоваться публикация приложения и проверка провайдером.

Instagram API поддерживает только аккаунты Business/Creator. Обычный личный аккаунт не является доступным универсальным способом входа.

Секреты зашифрованы в закрытом хранилище. Они не выдаются браузеру после сохранения и не входят в GitHub.
