Для Яндекса выберите второй режим в панели ИИ. До утверждения тарифа его может запускать только администратор.

Файлы Qwen передаются провайдеру по явному действию и не записываются на диск Покадрово. Хранение у провайдера определяется условиями вашего аккаунта.
