# Покадрово WEB

**Веб-редактор «Покадрово»: бело-синяя главная страница, переключаемая тёмная тема, вход в монтажёр через главное меню.**

### Как запустить локально

1. Установите Node.js 22 LTS.
2. Скачайте репозиторий (Code → Download ZIP) и распакуйте архив.
3. Windows: запустите `start-local.bat`. macOS/Linux: выполните `bash start-local.sh`.
4. Откройте [http://localhost:5173](http://localhost:5173).

Можно также вручную: `npm install`, `npm run dev`. Проверка: `npm run build`.

### Что уже работает

- Главная страница с переходом в монтажёр, карточками преимуществ и планами развития ИИ
- Светлая бело-синяя тема по умолчанию и тёмная тема по кнопке (сохранение темы в браузере)
- Загрузка видео и фотографий, таймлайн, разделение и обрезка, изменение порядка клипов, текст
- Предпросмотр, локальные проекты через localStorage / IndexedDB, экспорт WebM без аудио

### Что планируется

ИИ-анализ кадров, монтаж по текстовому описанию, автосубтитры, музыкальные рекомендации, экспорт MP4 с аудио, регистрация и защищённая админ-панель. Это **цели**, а не готовые функции.
