# Покадрово WEB

Отдельная веб-версия редактора «Покадрово».

**Открыть работающий сайт:** https://pokadrovo-studio.higgsfield.app

## Запуск исходников

Нужен Node.js 20.19+. Выполните `npm install` и `npm run dev`. Проверка и сборка: `npm run build`. Готовые файлы: `dist/`.

## Возможности

Импорт видео и фото, таймлайн, обрезка и разделение клипов, изменение порядка, текстовая надпись, предпросмотр, локальное сохранение через IndexedDB и localStorage, экспорт WebM без аудио.

## Текущие ограничения

Не подключены вход через Google/VK, серверная регистрация, платежи, ИИ и защищённая админка. Экспорт в MP4 с аудио ещё не реализован. Автоматическая синхронизация данного GitHub-репозитория с опубликованным сайтом пока не настроена.
