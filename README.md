# Покадрово WEB

Покадрово — будущий ИИ-монтажёр с собственной монтажной студией. Сейчас работают локальный бриф и ручной редактор; автоматический ИИ-монтаж пока не подключён.

## Локальный запуск

Установите Node.js 22, выполните `npm install` и `npm run dev`, затем откройте `http://localhost:5173`. Windows: `start-local.bat`. macOS/Linux: `bash start-local.sh`.

## Многослойная главная

Главная подключена к существующему редактору: передача задания, импорт файлов и открытие сохранённых проектов используют прежний контракт `AiHomeProps`. Код монтажа и экспорт не переписаны.

- Разные планы композиции: контурная типографика, калька, синяя подложка, фото, портрет, режиссёрская записка, контактная лента и бриф.
- Регулятор глубины и переключатель раскладки слоёв, параллакс, просмотр кадров, загрузка своих материалов.
- Сохранение черновика задания, светлая/тёмная темы, отключение движения и `prefers-reduced-motion`.
- Мобильная версия, клавиатурная навигация, диалог просмотра и валидация типов вложений.

Фотоматериалы встроены локально как WebP в `src/home/frame-*.ts` и экспортируются через `src/layered-assets.ts`; нет обращения к CDN. Источники перечислены в `ASSET-CREDITS.md`.

## Проверки

`npm run typecheck` и `npm run build`. GitHub Actions запускает только проверку и сборку. В этом обновлении нет публикации на хостинг, настройки домена или автодеплоя. После согласования дизайна публикацию выполняем отдельно.

Результаты и границы локальных проверок главной страницы описаны в `docs/HOMEPAGE-QA.md`.

## Ограничения

Текущий экспорт — WebM без звуковой дорожки. ИИ-агент, серверные аккаунты, платежи и MP4 с аудио ещё не реализованы. Локальные данные разных доменов и браузеров не синхронизируются автоматически.

Основной репозиторий: `krest0208/pokadrovo-web`. Android хранится отдельно в `krest0208/pokadrovo` и в этом обновлении не изменён.
