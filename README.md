# Покадрово WEB · 0.8

Покадрово — будущий ИИ-монтажёр со своей монтажной студией. Сейчас работают ручной редактор, бриф для ИИ, защищённая админ-панель, регистрация и профиль. Нейросеть пока не подключена.

## Запуск

Node.js **22.16+**. Из исходников: `npm install`, `npm run build`, `npm start`. Готовая локальная сборка с `dist` запускается без зависимостей: `start-local.bat` / `bash start-local.sh`.

Сайт: `http://localhost:5173`, профиль: `/profile`, редактор: `/studio`, админ-панель: `/admin`. Для разработки — `npm run dev` (Vite + Node API). Регистрация и админка не работают как отдельный HTML-файл без сервера.

## Что добавлено в 0.8

- Для создания, открытия и сохранения проектов требуется вход. Главная остаётся публичной.
- Регистрация по email и паролю, вход, профиль, изменение имени/пароля и выход.
- Раздельные серверные документы проектов и пространства локальных медиа для пользователей.
- Кнопка «Зарегистрироваться» в шапке, после входа — «Мой профиль»; нижняя кнопка блока площадок создаёт реальный проект выбранного формата.
- Владелец может войти с главной и перейти в профиль, редактор или админку. Изменение его логина и пароля доступно в админке.
- Список пользователей, поиск и настоящие показатели регистраций для владельца.
- Серверные обработчики Google / Facebook / Instagram OAuth и закрытые настройки Client ID/Secret в админке. До настройки кнопки отключены. **Instagram — только Business/Creator; это не вход для любых личных аккаунтов.** Реальный внешний OAuth ещё нужно проверить с приложениями владельца.

## Безопасность и данные

Обычная регистрация не выдаёт административных прав. Пароли хешируются scrypt; cookie-сеансы HttpOnly, CSRF и ограничения попыток; OAuth state одноразовый и привязан к браузеру; Google PKCE/nonce и проверка подписи токена. Client Secret хранится зашифрованным и не возвращается в панель. В публичном коде нет заранее созданного пароля владельца.

Первичная настройка владельца: `npm run admin:setup`. При работе с персональной приватной сборкой аккаунт уже создан в её локальной базе. **Не выкладывайте приватную сборку, `.pokadrovo-private`, SQLite, `master.key` и файл пароля в GitHub.**

Видео, фото и музыка остаются в браузере. Сервер хранит профиль и параметры монтажа, включая бриф. Перенос исходных медиа между компьютерами пока не реализован. Старую локальную библиотеку может явно восстановить владелец в своём профиле. Email-подтверждение письмом, восстановление пароля через почту и объединение социальных аккаунтов ещё не подключены.

## Сохранённые возможности

Многослойная главная, анимации при прокрутке и темы. Редактор обычного видео и Reels, обрезка, разделение, диапазоны, звук и музыка, скорость, трансформации и формы изображений, текст/шрифты, SRT, контекстное меню, ИИ-панель и отмена действий. Экспорт WebM со звуком. MP4 зависит от кодировщика браузера; универсальный MP4 не гарантируется.
