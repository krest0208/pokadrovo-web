# Покадрово WEB

**Покадрово** — веб-оболочка будущего ИИ-видеомонтажёра. Наш продукт — не классический редактор с дополнительной кнопкой ИИ, а интеллектуальная система, которая должна понимать запрос человека и в дальнейшем выполнять реальные операции на таймлайне. Пока ИИ-обработка находится в разработке.

## Где смотреть

Веб-сайт: https://pokadrovo-studio.higgsfield.app

Основной репозиторий: https://github.com/krest0208/pokadrovo-web

Android-проект (разрабатывается отдельно): https://github.com/krest0208/pokadrovo

## Запуск localhost

1. Установите Node.js 22 LTS с https://nodejs.org.
2. Скачайте репозиторий и распакуйте ZIP.
3. На Windows запустите `start-local.bat`, на macOS/Linux — `bash start-local.sh`.
4. Откройте `http://localhost:5173`.

Для ручного запуска используйте `npm install` и `npm run dev`. Для сборки: `npm run build`.

## Что сейчас работает

- Главное меню в бело-синем стиле с интерактивным монтажным визуалом, CSS-анимациями и переключением тёмной темы.
- Поле для описания желаемого монтажа. Текст превращается в **локальное задание проекта** и сохраняется вместе с проектом. Это **не запуск ИИ**, настоящая обработка ещё не подключена.
- Прикрепление видео и фото прямо на главной с переходом в редактор.
- Предложения типовых сценариев (заполняют поле, не выдают себя за ИИ).
- Монтажный интерфейс: медиатека, предпросмотр, таймлайн, текст, обрезка, разделение, перестановка клипов.
- Локальные проекты через IndexedDB/localStorage, экспорт видео **WebM без звука**.
- Фирменный знак Play + Pause (SVG), масштабирование таймлайна и горячие клавиши.

## Следующая цель

Подключить ИИ-агента, который преобразует текстовые инструкции в **проверяемый план монтажа**, вызывает реальные инструменты редактирования, показывает изменения на таймлайне и позволяет откатывать их.

ИИ-функции, распознавание речи, музыка, многодорожечный звук, серверные аккаунты, защищённая админка и MP4 с аудио пока не готовы.

В дальнейшем проверенные веб-функции отдельно переносим в **нативное** Android-приложение (не WebView).

## Дизайн

Главная переработана с опорой на удобство понятных AI-сервисов (визуальная демонстрация, три шага, заметный CTA), но копирования элементов и маркетингового текста Aidentika нет. Наши цвета — собственный бело-синий стиль с опциональной тёмной темой, фирменный логотип сохраняется.

Для анимаций используются transform, keyframes и интерактивное переключение состояний с учётом `prefers-reduced-motion`.
