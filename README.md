# Покадрово WEB

**Это самостоятельная локальная версия видеоредактора «Покадрово».** Для работы **не нужны Higgsfield, аккаунт хостинга, API-ключи или отдельный сервер**.

## Запустить на своём компьютере

1. Установи **Node.js LTS**: https://nodejs.org/ (Node.js 22 рекомендован).
2. Скачай репозиторий: нажми **Code → Download ZIP** на GitHub, затем распакуй ZIP. Либо клонируй его через Git.
3. **Windows:** дважды щёлкни файл `start-local.bat`. **macOS / Linux:** открой терминал в папке проекта и выполни `bash start-local.sh`.
4. После установки зависимостей открой в браузере **http://localhost:5173** (скрипт на Windows попытается открыть ссылку сам).

**Важно:** окно терминала нужно оставить открытым, пока работаешь с редактором. Чтобы остановить сайт, нажми **Ctrl+C** в терминале. Адрес `localhost` доступен только на том компьютере, где запущен сайт.

## Запуск вручную (для разработчика)

```bash
npm install
npm run dev
```

После запуска: http://localhost:5173

Проверка кода и сборка:

```bash
npm run typecheck
npm run build
```

Папка `dist/` содержит готовую статическую сборку; чтобы посмотреть её локально после сборки, используй `npm run preview` (http://localhost:4173).

## Что работает

- Импорт локальных видео и изображений
- Таймлайн, разделение и изменение границ клипов, изменение порядка
- Текст поверх видео, предпросмотр
- Сохранение проектов в этом браузере (IndexedDB и localStorage)
- Экспорт в WebM без аудио средствами браузера

## Ограничения

- Это **веб-приложение**, а не нативное APK.
- Пока нет Google/VK-входа, серверных аккаунтов, платежей, админ-панели и ИИ-функций.
- Экспорт **WebM без звука**, не MP4. Большие видео могут работать медленно.
- Медиа и проекты хранятся локально в конкретном браузере. Переход с онлайн-домена на `localhost` **не переносит** старые проекты автоматически. Не удаляй старые файлы до переноса.
- Шрифты включены в локальную сборку, поэтому сайт не обращается к Google Fonts при открытии.
- Работа с исходниками из этого репозитория **не обновляет** старый опубликованный сайт автоматически.
