# Покадрово WEB · единая сборка

Покадрово — ИИ-монтажёр со своей монтажной студией. Сборка объединяет главную, редактор, проекты, регистрацию и защищённую админ-панель. Подготовлены два режима: бесплатная проба Reels до 60 секунд через Qwen Omni и будущий платный монтаж через Яндекс AI Studio. Проба — один проект, три запроса, семь дней; владелец тестирует без пользовательских списаний. Яндекс пока работает с заданием и структурой проекта, без разбора исходного видео. Пользовательский тариф и платежи закрыты. Для запуска нужны отдельные ключи и включение в админ-панели; обновление кода не означает подключение моделей на сайте. Инструкция: [AI-ACCESS-AND-YANDEX.md](docs/AI-ACCESS-AND-YANDEX.md).

**Начать:** [START-HERE.md](START-HERE.md). **Размещение:** [DOMAIN-DEPLOY.md](DOMAIN-DEPLOY.md).

С 19 октября 2026 доступна регистрация по почте и паролю. Настройки production: `POKADROVO_ACCOUNTS_ENABLED=1`, `POKADROVO_GUEST_EDITING=1`, `POKADROVO_SOCIAL_LOGIN_ENABLED=0`. Гостевой монтаж и существующие локальные проекты сохранены. Инструкция: [EMAIL-ACCOUNTS.md](docs/EMAIL-ACCOUNTS.md).

## Запуск

Node.js **22.16+**. Из исходников: `npm install`, `npm run build`, `npm start`. Готовая локальная сборка с `dist` запускается без зависимостей: `start-local.bat` / `bash start-local.sh`.

Сайт: `http://localhost:5173`, проекты: `/projects`, редактор: `/studio`, админ-панель: `/krest0208!!!`. Для разработки — `npm run dev` (Vite + Node API). Регистрация и админка не работают как отдельный HTML-файл без сервера.

## Аккаунты по почте и паролю

- Можно монтировать без регистрации. После входа новые проекты сохраняются в аккаунте; гостевая библиотека остаётся отдельно в том же браузере.
- Регистрация по email и паролю, вход, профиль, изменение имени/пароля и выход.
- Раздельные серверные документы проектов и пространства локальных медиа для пользователей.
- Кнопка «Зарегистрироваться» в шапке, после входа — «Мой профиль»; нижняя кнопка блока площадок создаёт реальный проект выбранного формата.
- Владелец входит через обычную форму сайта по отдельному логину и паролю. Только в его меню, профиле и редакторе появляется кнопка «Админ-панель». Прямой вход `/krest0208!!!` сохранён. Серверные права не зависят от видимости кнопки. Создание отдельного владельца: [ADMIN-ACCOUNT.md](docs/ADMIN-ACCOUNT.md).
- Список пользователей, поиск и настоящие показатели регистраций для владельца.
- Сторонние способы входа скрыты и отключены на сервере, включая callbacks и настройки провайдеров. Сохранённый код OAuth требует отдельного явного включения и проверки перед будущим использованием.

## Безопасность и данные

Обычная регистрация не выдаёт административных прав. Пароли хешируются scrypt; cookie-сеансы HttpOnly, CSRF и ограничения попыток; OAuth state одноразовый и привязан к браузеру; Google PKCE/nonce и проверка подписи токена. Client Secret хранится зашифрованным и не возвращается в панель. В публичном коде нет заранее созданного пароля владельца.

Простой запуск и первичная настройка владельца: `start-standalone.bat` (Windows) или `bash start-standalone.sh` (macOS/Linux). При первом старте пароль задаётся в локальной форме браузера. Инструкция: [STANDALONE-START.md](STANDALONE-START.md). Терминальная альтернатива: `npm run admin:setup`. При работе с персональной приватной сборкой аккаунт уже создан в её локальной базе. **Не выкладывайте приватную сборку, `.pokadrovo-private`, SQLite, `master.key` и файл пароля в GitHub.**

При обычном монтаже видео, фото и музыка остаются в браузере. В пробном ИИ-режиме вошедший в аккаунт пользователь при доступной пробе может отдельно разрешить отправку выбранного MP4/WAV в Qwen: до 60 секунд и 12 MiB, без записи файла на диск сервера Покадрово. Сервер хранит профиль и параметры монтажа, включая бриф. Перенос исходных медиа между компьютерами пока не реализован. Старую локальную библиотеку может явно восстановить владелец в своём профиле. Email-подтверждение письмом, восстановление пароля через почту и объединение социальных аккаунтов ещё не подключены.

## Сохранённые возможности

Многослойная главная, анимации при прокрутке и темы. Редактор обычного видео и Reels, обрезка, разделение, диапазоны, звук и музыка, скорость, трансформации и формы изображений, текст/шрифты, SRT, контекстное меню, ИИ-панель и отмена действий. Экспорт WebM со звуком. MP4 зависит от кодировщика браузера; универсальный MP4 не гарантируется.
