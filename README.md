# Покадрово WEB

Покадрово — будущий ИИ-монтажёр с собственной монтажной студией. Сейчас работают локальный бриф и ручное редактирование. Автоматический ИИ-монтаж пока не подключён.

## Локальный запуск

Установите Node.js 22, выполните `npm install` и `npm run dev`, затем откройте `http://localhost:5173`. Windows: `start-local.bat`. macOS/Linux: `bash start-local.sh`.

## Редактор 0.5

- Режимы «Обычное видео» и «Reels / Shorts», форматы 16:9, 9:16, 1:1 и 4:5. Переключение сохраняет монтаж.
- Обрезка, разделение, дублирование, удаление и порядок клипов. Метки I/O и вырезание диапазона со сдвигом всех дорожек.
- Скорость 0.25–4x, длительность фотографий, масштаб, положение, поворот, отражение, вписать/заполнить.
- Звук исходного видео, импорт музыки, отдельные аудиоклипы, громкость, mute, плавное нарастание/затухание и отделение звука.
- Яркость, контраст, насыщенность, прозрачность и появление/исчезновение через чёрный.
- Несколько текстовых надписей с временем, размером, цветом и позицией; импорт SRT. Отмена/повтор до 60 изменений.
- Активная панель выходит на передний план; кнопка разворачивает её, Escape возвращает. На телефоне используются вкладки панелей.
- Один и тот же композитор и звуковой микшер используются для предпросмотра и экспорта.

**Экспорт:** WebM со звуком. MP4 предлагается только когда браузер сообщает о поддержке собственного кодировщика. WebM реально проверен; универсальный MP4/H.264/AAC ещё не гарантируется. Экспорт выполняется в реальном времени, вкладку нужно держать видимой. Есть прогресс и отмена.

## Главная и площадки

Существующая многослойная главная, viewport-анимации и фирменный знак сохранены. Добавлен выбор формата для Instagram Reels, TikTok, YouTube Shorts, обычного YouTube, VK Клипов и Telegram. Это пресеты проекта, **не автопубликация, подключение аккаунтов или гарантия соответствия всем требованиям площадок**.

Фотоматериалы главной встроены локально в `src/home/frame-*.ts`. Источники: `ASSET-CREDITS.md`. Для просмотра и редактирования не нужны CDN или Higgsfield.

## Данные и сохранение

Старые ключи `pokadrovo-projects-v1` и `pokadrovo-media-v1` сохранены. Чтение старого проекта добавляет новые значения по умолчанию; прежняя общая надпись преобразуется в текстовый слой. Нажимайте «Сохранить» после правок. Импорт медиа и возврат на главную также пытаются сохранить проект. При недоступном хранилище показывается предупреждение.

JSON-экспорт содержит монтаж и ссылки на локальные медиа, но **не сами видео, фото или музыку**. Для переноса на другое устройство нужны исходные файлы; автоматической синхронизации нет.

## Проверки

```
npm run typecheck
npm run build
node tools/test-editor.cjs
```

GitHub Actions выполняет проверку сборки и тесты модели. Команда тестов строго компилирует TypeScript редактора и запускает 120 проверок без новых зависимостей. Результаты локальных браузерных проверок и ограничения описаны в `docs/EDITOR-0.5-QA.md`.

## Границы текущей версии

Это рабочая основа, а не весь набор возможностей CapCut. Пока одна последовательная видеодорожка, несколько независимых аудио- и текстовых клипов. Нет наложения нескольких видеослоёв, keyframes, сложных переходов, автоматического шумоподавления, ИИ-агента, серверной авторизации и платежей. После отделения звук редактируется независимо от видео. Длинные проекты и все сочетания браузеров/кодеков ещё нужно тестировать.

Основной репозиторий: `krest0208/pokadrovo-web`. Android — отдельно в `krest0208/pokadrovo` и в этом обновлении не менялся. Публикация на хостинг и настройка домена **не выполняются**.

## Редактор 0.6

В редакторе появилась панель «Покадрово AI» с заданием и планом правок. Нейросеть пока
не подключена: кнопка запуска недоступна до настройки провайдера. Подготовлены типизированный
адаптер, JSON-протокол, проверка допустимых действий, защита от устаревших планов и применение
с одной отменой. Описание: `docs/AI-INTEGRATION.md`.

Правая кнопка мыши по дорожке открывает меню монтажа; на сенсорном экране используйте
кнопку `•••`, с клавиатуры — Shift+F10. Изображение можно двигать, растягивать и вращать прямо
в предпросмотре. Есть овальная/скруглённая маска, кадрирование и сохранение пропорций.
Шрифты, насыщенность, курсив и выравнивание текста сохраняются в проекте и используются
при экспорте. Кастомные шрифты подключаются через `src/editor/fonts.ts`; файлы добавим позже.

Новые тесты: `node tools/test-editor-features.cjs` после `npm install`.
Границы проверок: `docs/EDITOR-0.6-QA.md`. Публикации на хостинг нет.
